# Our Little Universe ❤️

موقع رومانسي تفاعلي — صفحة واحدة، كل حاجة فيها محلية (خطوط، صور، صوت، فيديو) من غير أي CDN.

## التشغيل

افتح `index.html` في المتصفح، أو ارفع محتويات المجلد ده على أي استضافة ملفات.

> كلمة السر: **أغسطس** (أو `8`).

## المحتوى

- `index.html` — الصفحة
- `css/` — الخطوط والهوية البصرية والحركات
- `js/` — الإعدادات، الرسائل، الذكريات، المؤثرات، مشغل الموسيقى، وربط كل حاجة
- `assets/` — الصوت، الفيديو، الصور، الخطوط (كلها محلية)

## النشر على GitHub Pages

Settings → Pages → Source: `main` / root → الرابط بيكون:
`https://<user>.github.io/bbf/`
